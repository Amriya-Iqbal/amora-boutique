# AMORA BOUTIQUE

A responsive fashion e-commerce website built with HTML, CSS and JavaScript.

**Live Demo:** https://amriya-iqbal.github.io/amora-boutique/

> **Note:** This is a frontend-only project. There is no backend or database.
> Cart and wishlist data are saved in the browser (localStorage), and the
> checkout and contact forms are for demonstration only.

## Features

- Shop page with search, category filter and sorting
- Product pages with size and colour selection
- Shopping cart with quantity controls and free-shipping progress bar
- Wishlist
- Contact form with validation


## Tech Stack

HTML, CSS, JavaScript
